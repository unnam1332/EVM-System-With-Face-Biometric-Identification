# EVM System with Face & Biometric Identification

## Project Overview
This project is an advanced Electronic Voting Machine (EVM) system integrated with Face Recognition and Fingerprint Authentication for secure voting.

## Technologies Used
- Python
- OpenCV
- Raspberry Pi
- Face Recognition
- Fingerprint Sensor

## Features
- Secure biometric authentication
- Face recognition verification
- Prevents fake voting
- Electronic vote storage
- Improved election security

## Hardware Components
- Raspberry Pi 3 Model B
- Camera Module
- Fingerprint Sensor
- Display Unit
- Power Supply
